個人情報の保護と完全ローカル管理についての誓約
守

本アプリケーション『Tsuzuri（つづり）』（以下「当アプリ」）は、ユーザーの皆様の大切な言葉とプライバシーの保護を極めて重要な責務と捉え、以下の通りプライバシーポリシー（以下「本ポリシー」）を定めます。

第1条

日記データおよび個人情報のローカル完結管理

1. 当アプリに入力された日記の本文、題名、天候、心模様、日時、および小冊子の編纂データは、すべてお客様の端末内部（ローカルストレージ・SQLiteデータベース）にのみ暗号的・安全に保存されます。

2. 当アプリが、ユーザーの事前の明示的な同意なく、日記本文等の個人的記録を当方の管理するサーバーや第三者のサーバーへ自動的にアップロードまたは送信することは決してありません。ユーザー登録やアカウント作成も一切不要です。

第2条

利用している外部サービスおよび品質解析について

当アプリでは、アプリケーションの安定稼働、クラッシュ障害の迅速な検知、および操作性改善を目的として、Google LLCが提供する以下の外部サービスを利用しています。

  • Firebase Crashlytics：クラッシュ障害ログの収集解析
  • Firebase Analytics：利用統計の匿名集計

これらのツールにより収集される情報は、端末識別子、OSバージョン、クラッシュ発生箇所のスタックトレース、機能利用イベント（執筆完了、縦書き/横書き切り替え等の統計）に限られます。ここにユーザーの日記本文・題名・個人的な文章情報は一切含まれず、個人を特定することはできません。

第3条

通知機能の取り扱い

毎夜の執筆リマインダー通知は、端末内部のシステムタイマー機能（AlarmManager）によって完全に端末内で完結して生成されるローカル通知です。通知送信を契機とした外部通信やユーザー識別情報の送信は行われません。

第4条

完全ローカル保存・プライバシー保護

当アプリで作成された日記および小冊子（ZINE）のすべてのデータは、端末内部にのみ保持されます。外部サーバーへの自動送信や他者への意図しない公開機能は一切存在せず、完全なプライベート空間として安心してご利用いただけます。

第5条

本ポリシーの改定

当アプリは、法令の改正や機能の追加に伴い、本ポリシーを改定することがあります。改定後のポリシーは、本ページまたはアプリ内にて掲示された時点より効力を生じるものとします。

Tsuzuri Privacy Policy Summary

1. 100% Offline & Local Storage: All journal entries, titles, weather icons, mood states, and compiled monthly booklets are stored strictly inside the device's local SQLite database. No account is required.

2. Zero Journal Content Transmission: The app never uploads, transmits, or syncs your diary entries or personal writings to any external server.

3. Anonymous Diagnostics Only: We use Firebase Crashlytics and Firebase Analytics solely to identify technical crash logs and anonymous aggregated usage metrics (e.g. app version, OS version). No diary text or personally identifiable information (PII) is ever collected.

4. Local Notifications: The optional evening reminder is triggered purely on-device via Android's AlarmManager without network transmission.

Contact: Please file issues or questions via our GitHub repository.

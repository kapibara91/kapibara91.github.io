# Agent Instructions & Workflow Rules

- **Git Commit & Push**: Whenever modifications or additions to pages/code are completed, automatically stage, commit with a concise, clear commit message, and push the changes to `origin master`.
- **Page Synchronization**: `index.html` (Japanese), `en.html` (English), and `cn.html` (Chinese) represent the developer's portfolio and support portal. Always ensure all three language versions remain synchronized in content and structure when making updates.
